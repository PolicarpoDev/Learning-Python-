# 🐍 Learning Python

Repositório criado para registrar minha evolução nos estudos de **Python**, reunindo exercícios, desafios e pequenos projetos desenvolvidos ao longo do aprendizado.

O objetivo é consolidar os fundamentos da linguagem e aplicá-los na prática, avançando gradualmente para conteúdos relacionados à análise, manipulação e processamento de dados.

## 📚 Conteúdos estudados

- ✅ Variáveis e tipos de dados
- ✅ Entrada e saída de dados
- ✅ Estruturas condicionais (`if`, `elif`, `else`)
- ✅ Laços de repetição (`while` e `for`)
- ✅ `range()`
- ✅ Listas, tuplas e dicionários
- ✅ Funções e reutilização de código
- ✅ Tratamento de erros com `try/except`
- ✅ Manipulação de arquivos
- ✅ Consumo de APIs com `requests`
- ✅ Manipulação de dados em JSON
- ✅ Introdução ao Pandas e DataFrames
- ✅ Exportação de dados para CSV e JSON

## 💻 Projetos e práticas

Durante os estudos, desenvolvi exercícios e pequenos projetos para aplicar os conceitos aprendidos, incluindo:

- 🎲 **Jogo de loteria:** sorteio de números, validação de entradas e controle de tentativas.
- 🌐 **Consulta de CEPs com a API ViaCEP:** consumo de API, coleta de informações, organização dos dados com Pandas e exportação para CSV e JSON.
